# DSU Pulse

Student services and campus life prototype for Dayananda Sagar University.

## Run locally

Open `index.html` in a browser. The sign-in, listings, requests, registrations, appointments, and other actions are prototype interactions; changes are kept in the current browser session.

## Project files

- `index.html` — app entry point
- `styles.css` — responsive design system and layouts
- `app.js` — screens, sample data, and interactions
